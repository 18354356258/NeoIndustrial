## v2.6.1 | 2026-07-15 — "TDengine 多变量落盘修复 & 跨页树联动 & 分组 GUID"

### 🔧 TDengine 8 变量仅 1 个落盘 — 根因修复

- **根因** — TDengine 正常表以 `ts` 列为唯一主键。`InsertRows` 循环中 8 个变量共享同一 `batch.Timestamp`，前 7 条 INSERT 被最后一条无声覆盖（REST API code=0）。SQLite/MySQL 等关系库用自增 ID 不受影响
- **修复** — 每行加 1ms 偏移 `dt.AddMilliseconds(rowIdx++)`，8 变量各得唯一时间戳
- **影响** — 仅 TDengine 写入路径（DatabaseWriteService.InsertRows TDengine 分支）

### 🤖 MCP TDengine 自述知识

- `introduce_platform("tdengine")` 新增话题，记录 4 项核心陷阱：ts 主键碰撞 / DDL 非标准 / 字段名映射 / REST 无连接池

## v1.6.0 | 2026-06-19 - "数据清洗增强版"

### 🧹 数据清洗大幅增强(9种清洗策略)

原有3种(死区抑制、限幅、异常值剔除3σ),本次新增6种:

**值修正类(自动修改值):**
1. **空值过滤** - NaN/Inf/负数检测,可替换为上次有效值或指定值
2. **死区抑制** - 小幅波动静默(已有,位置前移)
3. **尖峰抑制** - 单点跳变 MAD 法检测 + 中值替换
4. **变化率限制** - 相邻最大变化量钳制
5. **限幅** - Min/Max 硬限(已有)
6. **异常值剔除** - 3σ 统计剔除(已有)

**质量检测类(仅记录日志,不修改值):**
7. **冻结检测** - 连续 N 次不变告警
8. **IQR 四分位距检测** - 四分位距异常标记
9. **量程合理性** - 超量程标记

**管线执行顺序**:空值过滤 → 死区抑制 → 尖峰抑制 → 变化率限制 → 限幅 → 异常值剔除 → SPC → 冻结/IQR/量程(日志)

### 🔄 离线缓存与断点续传
- **OfflineCacheService.cs**: 全新服务,SQLite 本地缓存 + MQTT/DB 双目标独立补发
  - `offline_cache` 表:断网时仓储采集数据,need_mqtt / need_db 双标记

- **DatabaseWriteService** 重连机制重构:

  - `EnsureConnectionsHealthy()`: 对外统一接口,修复+ping 验证
  - `WriteBatchAsync()`: 写入失败→自动重连→重试,全流程在调用方无感

- **补发静默失败**: `catch { break; }` 无日志,加 Logger.Warn 记录失败原因
